# Madhuri Suguru Portfolio

Responsive single-page portfolio generated from the provided Madhuri Suguru Supply Chain resume.

## Files
- `index.html` — portfolio structure/content
- `style.css` — responsive design and theme
- `script.js` — mobile navigation, dark/light mode, scroll effects
- `Madhuri-Suguru-Resume.pdf` — the provided resume

## Run locally
No build tools are required.

Option 1:
Open `index.html` directly in a browser.

Option 2 (recommended):
Run a local static server from this folder, for example:
`python -m http.server 5500`

Then open:
`http://127.0.0.1:5500`

## Content policy for this portfolio
The portfolio content is based only on the supplied Madhuri Suguru resume. The reference portfolio was used only for design inspiration; its candidate names, experience, education, projects, contact details, and other candidate-specific content are not included.
